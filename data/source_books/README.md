# Source Books Directory (`data/source_books/`)

This directory is designated for storing raw scanned PDF source books of Myanmar Dhamma literature (different lead/metal movable typefaces and print editions).

## Guidelines
- Place newly acquired scanned PDF books directly into this folder.
- PDF files are excluded from Git (`.gitignore`) to keep the repository lightweight and adhere to GitHub's file size limits.
- The Gemini Lead Agent and automated pipelines discover, inspect, crop, and generate ground-truth training datasets from books stored here.
